# Decision log

One row per design decision. "Who decided" feeds the transcript ownership score and lets you answer honestly in the interview which parts you designed and which an AI tool generated.

| # | Decision | Alternatives considered | Why this one | Evidence | Who decided | Where in code |
|---|---|---|---|---|---|---|
| 1 | | | | | me / AI suggested, I accepted / AI suggested, I rejected | `path:line` |

Rules:
- Write the row when you make the decision, not afterwards.
- "Evidence" is a test, a diff, a measurement or a contract line. "Seemed better" is not evidence; mark it JUDGEMENT.
- Copy the reason into a comment beside the code it governs; the code grader reads only source.
