# V4 local tools

Use this only when the optional Python CLI is installed. Otherwise retain the
existing checkers and manual review. A skill-folder install alone is not the CLI.
Run `python -m orchestrate_toolkit COMMAND --help` for arguments.

| Need | COMMAND |
|---|---|
| Source-located requirement candidates | analyze |
| Input schemas, replay and controls | assess |
| Weighted local estimates and missing bounds | estimate |
| Fingerprinted experiments and decisions | memory |
| Evidence-linked advice | mentor |
| Questions and factual claims | interview |
| Edition checks and manual reviews | release-gate |
| Stage files and release policy | workflow |
| Redacted secret findings | security |

Interpretation, answer meaning and official scores can remain UNKNOWN. Hashes do
not prove truth. Unknown mandatory checks block local READY. No model or upload
runs implicitly. Authorized execution retains host permissions. Existing workflow
checkpoints keep legacy behavior unless initialized with a V4 policy.
