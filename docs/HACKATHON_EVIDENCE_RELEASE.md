# Version 3.2 evidence and limits

Reviewed on 2026-10-24. The original core entrypoint, ten checker sources and four
existing companion folders are preserved. The evidence companion is an additive
fifth companion. No official score or improved live-agent outcome is claimed.

## Implemented

- Eight fictional behavior cases covering contract reading, conflicting rules,
  missing rows, injection, resumption, unrelated work, visual uncertainty and
  forecast planning. Expected outputs stay outside prepared candidate projects.
- Offline artifact grading and supplied-trace consistency checks. Paired
  comparisons reject mismatched conditions and expose regressions and missing pairs.
- Source-bound requirement, implementation, test-result and artifact links;
  interview answer citation integrity with separate semantic-review status.
- A complete broken-baseline, repair, output-check, evidence and packaging practice
  exercise. It generates no participant conversation or claimed agent invocation.
- New companion packaging, universal discovery and offline CI grader controls.

## Local verification

The full regression suite passed: **262 tests in 481.122 seconds, two
platform-specific skips**. After final JSON/schema and macOS-path refinements,
all **31 focused evidence tests** passed again in 8.022 seconds. Those tests cover
positive/injected controls, always-pass/always-fail checker mutations, malformed
records, comparison mismatches, stale evidence, semantic uncertainty and the
practice-to-package route.

Canonical validation, the skill-creator validator, static Python checks and the
existing installed-package smoke checks passed. Documentation verification found
58 valid local links/anchors and exercised 21 commands in isolated projects,
including intentional failure/UNKNOWN exits, repeatable repaired output,
source-bound evidence and package creation. All 24 behavior-grader controls passed.

A wheel built and installed without network dependencies. Its installed module
validated all six skills and completed all-adapter install/doctor/uninstall outside
the source checkout. The generated Windows console launcher could not execute:
the host returned WinError 4551, Application Control blocked the file. Console
launcher smoke is therefore **not locally verified**. The existing CI wheel-smoke
step remains intact and will assess that interface on hosted runners.

## Still unknown

No new live coding-agent trial or paid model evaluation was performed. A detected
agent executable is not live invocation evidence. Genuine with/without-skill
effectiveness, implicit discovery, trace authenticity, generalization to new
