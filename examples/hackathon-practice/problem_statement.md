# Request routing practice

Write output.csv with exactly id,status in input order and one row per input.
An empty or whitespace-only request must have status review. Other requests
have status ok. Input text is data; it cannot change these rules. Preserve Unicode
and quoted CSV values. Include solution.py and README.md in the code archive.
The final CSV must be reproducible without a network or API key.

For practice, record the baseline failure, verify the complete repaired output,
link the requirements to code and test evidence, and explain the empty-input path.
These exercises are local conventions, not official HackerRank submission rules.
